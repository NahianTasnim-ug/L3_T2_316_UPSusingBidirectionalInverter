# L3_T2_316_UPSusingBidirectionalInverter
Smart Grid Type UPS Using Bidirectional Inverter

This project presents the design and implementation of a Smart Grid Type Uninterruptible 
Power Supply (UPS) using an inverter system. It aims to develop a smart UPS that charges 
a 12V DC battery using solar energy. An inverter circuit turns this energy into a useful AC 
signal to power diverse loads. When the battery of the UPS is fully charged, the system 
feeds the extra power to the grid. The proposed UPS integrates a push-pull inverter and a 
solar charging unit, aiming to enhance energy efficiency and sustainability. The push-pull 
inverter is designed to convert DC power from the battery or solar panel into AC power 
with high reliability and efficiency. The solar charger is implemented to harness renewable 
solar energy, ensuring a sustainable power source while reducing dependency on 
conventional grid power. Thus, this project demonstrates a practical and eco-friendly 
solution for reliable power backup and energy management in modern households and 
small-scale industries.
